# Raitha-Varta

Raitha-Varta is a Smart-inspired agriculture advisory Android application designed to provide short and actionable farming tips using flash-card style UI.

## Features
- Daily agriculture tips
- Swipeable flash cards
- Crop-specific guidance
- Success stories
- Expert ask module

## Technologies
- Kotlin
- XML
- Android Studio
- ViewPager2
- RecyclerView

## Objective
To simplify complex agricultural advisories into easy-to-understand mobile guidance for farmers.
